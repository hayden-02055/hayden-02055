## Featured Projects

### Sentinel Club · Private

A development harness that turns natural-language requests into an explicit contract,
then coordinates LLM agents to design, implement, verify, and repair code.
Human approval and checks against intent and scope are central to the workflow.

### Sentinel Forge · Private

A research and evaluation toolkit for Sentinel Club. It records execution traces,
artifact history, and model calls to support reproducible experiments and independent
assessment of requirements and generated outputs.

### [SkillFetch](https://github.com/hayden-02055/SkillFetch) · Experimental

A CLI that discovers Agent Skills on GitHub for a given task, ranks them with an LLM,
and performs static checks before loading a skill with user approval.
